# Открытые вопросы перед разработкой

## Партнёр
1. Какой точный тип партнёрского аккаунта у нас?
2. Есть ли API, который выдаётся отдельно от broker-admin?
3. Есть ли API docs / SDK / webhooks?
4. Можно ли white-label приложение под своим брендом?
5. Разрешена ли browser/RPA automation?
6. Какие операции доступны через broker account?
7. Какая wholesale стоимость Premier/Platinum?
8. Какая комиссия recharge?
9. Какая комиссия card payment / FX?
10. Какие chargeback/reversal fees?
11. Кто делает KYC и сколько он стоит?
12. Можно ли Apple Pay / Google Pay? Конкретно: (а) принимает ли Wallet карту Premier Virtual при ручном добавлении — проверить на одной из уже выпущенных карт; (б) есть ли у эмитента In-App Provisioning (кнопка «Добавить в Apple Wallet» в приложении: нужен API эмитента и разрешение Apple на entitlement payment-pass-provisioning).
13. Можно ли P2P/card-to-card/remittance?
14. Можно ли получать transaction events/webhooks?
15. Как безопасно получать/display card details?
