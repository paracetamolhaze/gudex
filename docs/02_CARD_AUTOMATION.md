# Автоматизация broker-admin

## Проблема
В текущем broker-admin нет доступного API, а вручную обрабатывать каждую заявку невозможно.

## Решение
Создать собственный backend API GUDEX, который принимает действия от мобильного приложения и выполняет их в partner-admin автоматически.

Пример:

`POST /cards/create`

Внутри backend:
1. Проверяет данные пользователя.
2. Создаёт задачу в очереди.
3. Автоматизированный браузер открывает broker-admin.
4. Заполняет необходимые поля.
5. Нажимает создание карты.
6. Получает результат.
7. Сохраняет статус в нашей БД.
8. Возвращает результат приложению.

## Технология
Предпочтительно:
- Playwright;
- отдельный worker/очередь;
- стабильные селекторы;
- retries;
- idempotency;
- audit log.

AI computer-use можно использовать только как fallback. Для финансовой панели основной поток должен быть детерминированным.

## Лучший сценарий
До RPA проверить network requests самой админки. Если панель внутри использует стабильные разрешённые HTTP endpoints и условия партнёрства позволяют их использовать, это быстрее и надёжнее браузерного робота.

## Критичные состояния
- session expired;
- 2FA;
- CAPTCHA;
- изменение DOM;
- duplicate submission;
- partner downtime;
- delayed KYC;
- карта создана, но ответ нашего worker потерян.

Для каждого должна быть обработка и ручной fallback.
